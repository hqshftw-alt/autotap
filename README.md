# AutoTap

تطبيق أندرويد للاستخدام الشخصي: يراقب الشاشة عبر خدمة إمكانية الوصول،
ولما يظهر نص/وقت معيّن تحدده أنت (مثل `07:01`)، يضغط تلقائياً على زر
تحدد نصه أنت أيضاً (مثل `حجز فترة الدوام`).

## البناء (تلقائي عبر GitHub Actions)

1. ارفع هذا المجلد لمستودع GitHub جديد وسوّي push لـ `main`.
2. روح لتبويب **Actions** → آخر run → **Artifacts** → حمّل `AutoTap-debug-apk`.
3. أو من تبويب **Releases** إذا كنت على main.

## التثبيت

- فك ضغط ملف الـ artifact تحصل `AutoTap-debug.apk`.
- فعّل "تثبيت من مصادر غير معروفة" بجهازك، وثبّت الملف.
- أو عبر adb: `adb install -r AutoTap-debug.apk`

## الإعداد داخل التطبيق

1. افتح AutoTap.
2. اكتب في **"النص/الوقت اللي نراقبه"** النص اللي يظهر بشاشة تطبيق الحجز
   عشان تعرف إن الوقت وصل (مثال: `07:01`).
3. اكتب في **"نص الزر"** نص الزر اللي تبيه يُضغط تلقائياً (مثال:
   `حجز فترة الدوام`) — يفضّل تتأكد إن النص مطابق تماماً لما هو ظاهر
   بالتطبيق.
4. (اختياري) إذا الحجز يحتاج خطوتين — يعني بعد ما يضغط "حجز فترة الدوام"
   يطلع نافذة/رسالة فيها زر تأكيد ثاني — اكتب نص هذا الزر في **"نص زر
   تأكيد الحجز"** (مثال: `تأكيد`). الخدمة تضغطه تلقائياً بمجرد ما يظهر
   بالشاشة، بشكل مستقل عن النص المراقَب في الخطوة الأولى.
5. (اختياري) حط حزمة تطبيق الحجز في **"حزمة التطبيق"** عشان الخدمة
   تشتغل بس جوه هذا التطبيق فقط وما تتفاعل مع تطبيقات ثانية.
6. اضغط **"حفظ الإعدادات"**.
7. اضغط **"فتح إعدادات إمكانية الوصول"** ودوّر على AutoTap وفعّله يدوياً
   (خطوة تسويها مرة وحدة، أندرويد يتطلبها لأي تطبيق يستخدم Accessibility).
8. فعّل المفتاح العلوي "تفعيل الأتمتة".
9. افتح تطبيق الحجز واتركه بالشاشة اللي فيها الوقت والزر — الخدمة تراقب
   بالخلفية، تضغط زر الحجز أول ما يظهر النص المحدد، وتضغط زر التأكيد
   (إذا حددته) بمجرد ما يظهر بعده.

## ملاحظات مهمة

- هذا التطبيق يعمل فقط على **حسابك أنت** وبنفس الطريقة اللي تسوّيها يدوياً
  (يبحث عن نص ويضغط زر) — ما يخترق ولا يتلاعب بأي بيانات.
- بعض التطبيقات تمنع الأتمتة بشروط استخدامها، تأكد من مراجعة شروط تطبيق
  الحجز قبل الاستخدام.
- الأيقونة الحالية مؤقتة (شفافة 1×1) — استبدلها لاحقاً بصورة حقيقية
  72×72 بكسل في `app/src/main/res/mipmap-hdpi/ic_launcher.png`.
- يحتاج Android 7+ (API 24).
